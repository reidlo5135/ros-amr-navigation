# amr_viz

`amr_viz` is the standalone React + TypeScript web client for this project.

It is no longer a ROS package. Transport ownership is outside this project and
belongs to:

- `amr_mqtt_bridge`
- `amr_mqtt_robot_plugin`

## Layout

- `src/`
  - React UI, Three.js scene, MQTT client
- `index.html`
  - Vite entry HTML
- `package.json`
  - frontend dependencies and scripts
- `vite.config.ts`
  - Vite dev/build configuration

## Requirements

- Node.js
- npm

The browser client expects an MQTT broker with WebSocket support. Typical dev
deployment:

- MQTT broker TCP: `1883`
- MQTT broker WebSocket: `9001`
- Vite dev server: `5173`

## Runtime

The web client connects to MQTT over WebSocket.

Default broker URL selection:

- `VITE_AMR_VIZ_MQTT_URL` if set
- otherwise `ws://<current-host>:9001/mqtt`
- or `wss://<current-host>:9001/mqtt` for `https:`

The client currently consumes modeled visualization topics such as:

- `amr/viz/telemetry/robot_pose`
- `amr/viz/telemetry/global_path`
- `amr/viz/telemetry/local_path`
- `amr/viz/telemetry/map`
- `amr/viz/telemetry/global_costmap`
- `amr/viz/telemetry/local_costmap`
- `amr/viz/telemetry/motion_status`
- `amr/viz/telemetry/obstacle_report`

These topics are emitted by VBox-side `amr_mqtt_bridge`.

and emits commands directly to MQTT:

- `amr/command/navigate_to_pose`
- `amr/command/set_initial_pose`

## Web Dev Run

Install dependencies:

```bash
cd amr_viz
npm install
```

Start the development server:

```bash
cd amr_viz
npm run dev
```

Typical host-PC access:

```text
http://<ubuntu-server-ip>:5173
```

## Notes

- this package no longer contains a ROS bridge or Electron shell
- `node_modules/` is generated by `npm install` and is intentionally not kept in git
- transport and ROS mirroring should remain in the MQTT packages, not here
