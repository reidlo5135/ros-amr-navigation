# amr_navigation

Metapackage for the active AMR navigation stack.

## Included Packages

- `amr_msgs`
- `amr_map_server`
- `amr_localization`
- `amr_costmap_server`
- `amr_global_planner`
- `amr_controller_server`
- `amr_recovery_server`
- `amr_runtime_observation`
- `amr_rviz`
- `amr_visualization`
- `amr_bt_navigator`
- `amr_lifecycle_manager`
- `amr_bringup`
- `amr_mqtt_server`

## Notes

- `amr_obstacle_detection` is no longer used.
- `amr_rviz_plugins` is no longer used.
- the ROS-native local operator UI lives in `amr_visualization`.
