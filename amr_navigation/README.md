# amr_navigation

Metapackage for the active AMR navigation stack.

## Included Packages

- `amr_msgs`
- `amr_map_server`
- `amr_localization`
- `amr_costmap_server`
- `amr_global_planner`
- `amr_local_planner`
- `amr_motion_controller`
- `amr_recovery_server`
- `amr_bt_navigator`
- `amr_lifecycle_manager`
- `amr_bringup`
- `amr_mqtt_server`

## Notes

- `amr_obstacle_detection` is no longer used.
- `amr_rviz_plugins` is no longer used.
- the operator UI now lives in the external `ros-rcs` desktop app repository.
